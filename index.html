快速上手

三步开始管理数据库

无需复杂配置，打开应用即可连接、浏览、操作。

01

创建连接

点击工具栏「连接」，填写主机、端口（默认 3306）、用户名与密码，点击「测试连接」确认可用。

02

浏览对象

左侧树形面板展开数据源，即可浏览数据库、表、视图、函数、触发器等对象结构。

03

查询与编辑

打开 SQL 编辑器执行查询，或在数据表中直接增删改；所有操作记录自动进入操作日志。

为效率而生

本地运行，数据不离桌

SooBoo 不依赖浏览器网络，连接信息保存在本地 JSON，查询结果即时渲染。支持断线重连、查询中断、后台导入导出，长时间任务也能安心处理。

  • 连接池在主进程管理，稳定高效
  • 执行中的查询可随时中断
  • 后台任务完成后系统通知 + 任务栏闪烁
  • 已保存查询与操作日志本地持久化

常见问题

有问题？先看这里

SooBoo 支持哪些平台？

目前 Windows 版本已可下载使用，macOS 与 Linux 版本正在筹备中，敬请期待。

SooBoo 是免费吗？

大部分常用功能无需登录即可免费使用；数据/结构传输同步等高级功能需要登录或者升级 PRO 后使用。

连接信息保存在哪里？

未登录时，所有连接配置、已保存查询、操作日志均通过系统级加密保存在本地；登录后采用动态密钥混合模式加密，在保证安全的前提下实现云同步。

支持哪些 MySQL 版本？

支持主流 MySQL 5.7 / 8.0 及以上版本，以及兼容 MySQL 协议的 MariaDB 等。

如何导入大体积 SQL 文件？

通过「文件 → 导入」选择 SQL 文件，任务会在后台运行。即使关闭弹窗，导入仍会继续，完成后会通过系统通知提醒。
